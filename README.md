# Dias Limpos

App (PWA) para celular e web: contador de dias, horas e minutos sem pornografia, check-in diário
(assistiu ou não, sentimento, o que quer melhorar), últimos 30 dias e diário.

Arquivos: index.html (o app inteiro), manifest.webmanifest e sw.js (instalação e uso offline), ícones.
Os dados ficam salvos só no aparelho (localStorage). Para instalar no celular, o app precisa estar
hospedado em um endereço https (ex.: GitHub Pages, Netlify ou Vercel); depois é só abrir no navegador
e usar "Adicionar à tela inicial".
